# 🤝 Contributing to Kala ki Dor

Thank you for your interest in contributing to **Kala ki Dor**! We are thrilled to welcome community contributions to help empower artisans through tech and design.

---

## 📋 Code of Conduct

- Be respectful, inclusive, and welcoming to all contributors.
- Keep discussion constructive and focused on empowering artisans and improving user experience.

---

## ⚙️ How to Contribute

### 1. Finding or Reporting Issues
- Check existing [GitHub Issues](https://github.com/YOUR_USERNAME/craft-for-cause/issues) before opening a new one.
- If you find a bug or have a feature idea, open a new Issue describing:
  - What the bug/feature is
  - Steps to reproduce (if applicable)
  - Expected vs actual behavior

### 2. Making Code Changes
- **Keep it Vanilla**: Use clean HTML5, vanilla CSS3, and modern ES6 JavaScript. Avoid adding heavy framework dependencies unless discussed.
- **Maintain Design Tokens**: Use variables defined in `style.css` (`:root` variables) for consistent colors, fonts, and spacing.
- **Responsiveness**: Ensure all new components look great on mobile, tablet, and desktop screens.

### 3. Pull Request Guidelines
- Branch naming convention: `feature/name-of-feature` or `fix/issue-description`.
- Keep commits clear and concise (e.g., `Add: Return policy modal accessibility aria-labels`).
- Fill out the PR description template detailing the changes made.

---

Thank you for supporting **Kala ki Dor**! Every commit helps build a stronger tomorrow for our artisan community.
