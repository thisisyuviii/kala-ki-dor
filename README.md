## 🌟 About the Project

**Kala ki Dor** is a social enterprise brand and digital platform dedicated to empowering traditional women artisans, LGBTQ+ community members, and individuals from marginalized backgrounds through skill training, dignified employment, and mental health awareness.

Every knot, stitch, and creation carries a thread of love, providing dignity and self-reliance to local artisans across India.

---

## 🚀 Key Features

- **Responsive Design**: Custom modern UI built with vanilla HTML5, CSS3, and JavaScript.
- **Top Tab Navigation**: Clean, accessible header with dropdown Mega Menu for product discovery.
- **Hero Showcase**: Full background artisan photograph highlighting the brand's core mission.
- **Three Pillars of Change**: Dedicated cards highlighting **Training**, **Empowerment**, and **Mental Health**.
- **Handcrafted Catalog**: Organized into `Crochet Items`, `Crochet Accessories`, and `Chenille Products`.
- **Dedicated Product Showcase Pages**: Dynamic product viewer (`product-detail.html`) featuring multi-photo thumbnail galleries.
- **Interactive Return Policy**: Modal window detailing handcrafted authenticity, 24-hour exchange guidelines, and unboxing video rules.
- **Direct Ordering**: Seamless WhatsApp and Instagram (`@kalakidor`) ordering integrations.

## 🛠️ Local Setup & Running Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/craft-for-cause.git
   cd craft-for-cause
   ```

2. **Run Local Server**:
   You can serve the static files using Python's built-in HTTP server:
   ```bash
   python -m http.server 8080
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8080` in your web browser.

## 🤝 How to Contribute

We welcome contributions from developers, designers, and cause advocates worldwide! Whether you want to improve accessibility, add new product categories, fix UI styling, or enhance responsiveness, your help makes our thread stronger.

### Contribution Steps:

1. **Fork the Repository**:
   Click the **Fork** button at the top right of this repository to create your own copy.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/craft-for-cause.git
   cd craft-for-cause
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Your Changes & Test**:
   - Ensure clean, semantic HTML5 and vanilla CSS/JavaScript.
   - Test your changes locally in your browser (`http://localhost:8080`).

5. **Commit Your Changes**:
   ```bash
   git commit -m "Add: brief description of your contribution"
   ```

6. **Push to Your Fork**:
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request (PR)**:
   Navigate to the original repository on GitHub and click **Compare & Pull Request**. Provide a clear summary of your changes.
